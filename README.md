# Между строк — книжный клуб

Адаптивный русскоязычный сайт на React + Vite. Включает каталог 22 книг, поиск, фильтры, карточки, книжную рулетку и общий рейтинг без регистрации.

## Запуск локально
1. Установите Node.js 20 или новее.
2. В корне проекта выполните `npm install`.
3. Скопируйте `.env.example` в `.env` и заполните переменные Supabase (для демо каталог работает и без них).
4. Выполните `npm run dev`.

## Общий рейтинг без регистрации
1. Создайте проект на https://supabase.com.
2. В SQL Editor выполните содержимое `supabase/schema.sql`.
3. В настройках проекта возьмите Project URL и anon/public key.
4. Запишите их в `.env` как `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
5. Перезапустите `npm run dev` или соберите сайт заново.

Участницы не создают аккаунты: браузер генерирует случайный идентификатор и сохраняет его локально. Повторная оценка с того же браузера обновляет прежний голос. Это удобный клубный механизм, но не строгая защита от накрутки: очистка данных браузера или другое устройство позволит проголосовать ещё раз. Не публикуйте service-role key — на клиенте допустим только anon key.

## Публикация на GitHub Pages
1. Создайте публичный GitHub-репозиторий и загрузите файлы проекта.
2. В Settings → Secrets and variables → Actions добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
3. В Settings → Pages выберите GitHub Actions.
4. В проекте уже добавлен `.github/workflows/deploy.yml`; загрузите его вместе с остальными файлами. После push в `main` GitHub Actions соберёт и опубликует сайт.
